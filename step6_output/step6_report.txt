CAVEATS
----------------------------------------------------------------------
  LIKELY FAILURE rows are NOT Tm-modeled: primer3's calc_heterodimer
  searches for the best local partial alignment rather than scoring
  Step 4's known fixed-frame binding site, and at high mismatch
  counts it finds a short unrelated sub-stretch instead, producing
  physically nonsensical Tm values (verified: -25C duplex Tm, an
  '89C shift', for one WEIDMANN2004_ENZ_P case). Mismatch count/
  3'-position is already decisive at this tier - that is why Step 5
  calls it LIKELY FAILURE in the first place.
  0 REDUCED worst-component rows use a primer/probe with an
  IUPAC degenerate base (incl. inosine-derived N). Those positions
  were realized against the actual genome base using Step 4's own
  match/mismatch/skip rule before Tm modeling, so mismatch counts
  here always agree with Step 4/5 - see realize_duplex() in this script.
  0 REDUCED worst-component rows have a real N in the genome
  window (sequencing ambiguity). Realized as a non-penalizing perfect
  pair (Step 4's 'skip, not scoring' rule for genome N), not a mismatch.
  Tm shift predicts risk; it does not prove assay failure. Wet-lab
  confirmation remains the final word.
